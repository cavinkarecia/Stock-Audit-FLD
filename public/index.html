Makes an Excel file with these sheets: Report card (exactly the data on the report card), Summary, SKU wise (one row per SKU code with system, physical, difference, and buffer or forward stock), Buffer detail and Forward detail (product name, system and physical cases, difference, value), Product wise (every product and MRP line), Final buffer and forward (the bill list and the sales return list with totals), plus Unsaleable when counted.
